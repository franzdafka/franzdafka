# David Chuev
Quantitative developer focused on financial modelling and ML applications. Currently studying Economics at Paris 1 Panthéon-Sorbonne.

### Projects

**[Credit Risk Assessment Service](https://github.com/franzdafka/credit-risk-analysis)**
Credit scoring service benchmarking four ML models on the German Credit Dataset, with SHAP-based decision explanations and cost-sensitive threshold optimization. XGBoost selected on test performance: AUC-ROC 0.787, Gini 0.574, KS 0.462.

**[Portfolio Optimization — Markowitz Mean-Variance](https://github.com/franzdafka/portfolio-optimization)**
Mean-variance optimization from scratch (scipy SLSQP): efficient frontier, GMV and tangency portfolios, concentration limits, and Black-Litterman return blending. Applied to real S&P 500 data; Black-Litterman improves Sharpe from 0.34 (uncapped) to 0.44 by stabilizing noisy return estimates rather than constraining weights.
